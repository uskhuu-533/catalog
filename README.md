# HUVTSAS каталог

Next.js дээрх хувцасны каталог. Барааны мэдээлэл MongoDB Atlas-д, зураг Cloudinary-д хадгалагдана.

## Асаах

1. `npm install`
2. `.env.example` файлыг `.env.local` нэрээр хуулж, Atlas болон Cloudinary-ийн өөрийн утгуудаар солино.
3. Atlas-ийн **Network Access** хэсэгт серверийнхээ IP хаягийг зөвшөөрнө.
4. `npm run dev` ажиллуулаад `http://localhost:3000` нээнэ.

`MONGODB_DB` нь өгөгдлийн сангийн нэр бөгөөд хүсвэл сольж болно. Cloudinary API secret зөвхөн сервер талын `.env.local` файлд байх ёстой.

Зөвшөөрөгдөх зураг: JPG, PNG, WebP, GIF (8 МБ хүртэл). Вэбээс бараа бүртгэж, нэр, өнгө, тайлбар, размераар хайх, ангилал болон размераар шүүх боломжтой.
